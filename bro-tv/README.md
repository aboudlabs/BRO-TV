# BRO TV 🍿

غرفة مشاهدة مشتركة (Watch Party) — Next.js 14 (App Router) + TypeScript + Tailwind + Supabase Realtime (Broadcast & Presence) — **بدون أي جداول قاعدة بيانات**.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم ضع NEXT_PUBLIC_SUPABASE_URL و NEXT_PUBLIC_SUPABASE_ANON_KEY
npm run dev                  # http://localhost:3000
```

الإنتاج: `npm run build && npm start` (أو انشره على Vercel وأضف المتغيرات في Environment Variables).
فحوصات الجودة: `npm run typecheck` و `npm run lint`.

## إعداد Supabase (دقيقة واحدة)

1. أنشئ مشروعاً مجانياً على supabase.com.
2. من **Project Settings → API** انسخ `Project URL` و `anon public key` إلى `.env.local`.
3. لا حاجة لإنشاء جداول. تأكد فقط أن **Realtime** مفعّل (افتراضياً مفعّل) وأن خيار *Allow public access* في إعدادات Realtime غير معطّل.

## لماذا كانت المزامنة لا تعمل؟ وكيف حُلّت

سيرفرات الأفلام الأربعة (VidSrc / 2Embed / MultiEmbed / AutoEmbed) تعمل داخل `iframe` من موقع آخر، والمتصفح **يمنع** أي موقع من التحكم بمشغّل داخل iframe من نطاق مختلف (Same-Origin Policy). لذلك لا يستطيع أي موقع تشغيله/إيقافه/تقديمه برمجياً مهما كانت الحيلة. الحل في ثلاث طبقات:

| الطريقة | ما الذي يتزامن | متى تستعملها |
|---|---|---|
| **المكتبة المجانية** (أرشيف الإنترنت) | تشغيل · إيقاف · قفز · انضمام متأخر — تلقائياً وبالكامل | أفلام ومسلسلات وكرتون ملكية عامة / تراخيص مفتوحة |
| **بث الشاشة** (WebRTC) | كل شيء، لأن الجميع يرى نفس الصورة بالضبط | أي محتوى حتى سيرفرات iframe: افتح الفيلم في تبويب واحد واضغط «بث الشاشة» |
| **الكتالوج العالمي** (Cinemeta + iframe) | يدوي فقط: زر «مزامنة المشهد» يبدأ عدّاً تنازلياً 3-2-1 | عندما لا يتوفر الفيلم في المكتبة المجانية ولا تريد البث |

### المكتبة المجانية (مزامنة كاملة)

- المصدر: أرشيف الإنترنت (archive.org) — أقسام: أفلام كاملة، كوميديا، خيال علمي ورعب، جريمة وغموض، أفلام صامتة، كرتون، مسلسلات قديمة، وأفلام Blender المفتوحة (Sintel وغيرها).
- يُشغَّل الملف داخل `<video>` تابع للموقع نفسه، لذلك يمكن التحكم به ومزامنته.
- عند وجود عدة جودات يُختار تلقائياً أنسب ملف (لا يتجاوز ~6 Mbps)، ولكل شخص أن يبدّل الجودة عنده فقط دون التأثير على الآخرين، ويكمل من نفس الموضع.
- إن فشل ملف، ينتقل المشغّل تلقائياً إلى النسخة التالية المتاحة.
- العناصر التي تحوي عدة ملفات (مسلسل كامل) تظهر لها قائمة «الحلقات والأجزاء».
- يُخفى كل عنوان غير مناسب لمشاهدة عائلية (مرشّح على العناوين والوسوم).
- إن حُجب `archive.org` من متصفح المستخدم (CORS/شبكة) تُمرَّر الطلبات عبر `/api/archive` على خادمك. هذا المسار يقبل فقط `advancedsearch.php` و `metadata/<id>` من `archive.org` ويرفض أي نطاق آخر.
- **المحتوى هنا قانوني ومجاني**؛ الأفلام الحديثة التجارية غير متوفرة كروابط مباشرة. لمشاهدتها معاً استعمل «بث الشاشة».

### بث الشاشة

- يعمل من متصفح سطح المكتب (Chrome / Edge / Firefox). الجوال لا يدعم بث الشاشة، لكن يستطيع **المشاهدة**.
- التشوير يمرّ عبر قناة Supabase نفسها (بدون خادم إضافي). الاتصال بين الأصدقاء مباشر (Mesh) بجودة حتى 3 Mbps لكل مشاهد، لذلك يُنصح بما لا يزيد عن 4–5 مشاهدين.
- المحتوى المحمي بـ DRM (نتفلكس وأمثالها) يظهر أسود — هذا قيد من المتصفح لا يمكن تجاوزه.
- بعض الشبكات (4G الصارمة، شبكات الجامعات) تمنع الاتصال المباشر. حينها أضف خادم TURN (مثلاً من metered.ca أو coturn) في `.env.local`:

```env
NEXT_PUBLIC_TURN_URL=turn:YOUR-TURN-HOST:3478,turns:YOUR-TURN-HOST:5349
NEXT_PUBLIC_TURN_USERNAME=...
NEXT_PUBLIC_TURN_CREDENTIAL=...
```

- لمشاركة الصوت: في نافذة اختيار المشاركة فعّل «Share tab audio» (Chrome) واختر **تبويب** وليس الشاشة كاملة.

### الترجمة

زر «تحميل ملف ترجمة» يقرأ `.srt` و `.vtt` (UTF-8 أو UTF-16 أو windows-1256 للعربية القديمة)، مع أزرار ±0.5 ثانية لضبط التوقيت. الترجمة تظهر عند من حمّلها فقط.

### تفاصيل المزامنة (للمطوّرين)

- أحداث Broadcast: `media` · `playback` · `hb` · `sync` · `countdown` · `rtc` · `request_state` · `state` · `chat` · `reaction`، والحضور عبر Presence.
- كل مشغّل يتجاهل الأحداث التي سببها هو (حراس منفصلة للتشغيل/الإيقاف/القفز) فلا يحدث «صدى» بين الأطراف.
- أقدم عضو في الغرفة يبثّ نبضة كل 4 ثوانٍ، ومن ينحرف أكثر من 1.5 ثانية يُصحَّح تلقائياً.
- من ينضم متأخراً يستلم الفيلم ووقته وحالته (يعمل/موقوف) مع تعويض زمن الوصول.
- إن منع المتصفح التشغيل التلقائي تظهر طبقة «اضغط للانضمام»، وعند الضغط يلحق بوقت الغرفة الحالي **دون** إرسال أي أمر للآخرين.

معرّفة في `tailwind.config.ts` (`brand`, `ink`, `champagne`). الخط Cairo مُضمَّن مع الموقع (`@fontsource-variable/cairo`) ولا يعتمد على Google Fonts.

## هيكل المشروع

```
app/            layout + الصفحة الرئيسية + /room/[roomId] + /api/archive
components/     الواجهة (RoomClient, RoomStage, Chat, LibraryModal, …) + player/ + library/
hooks/useRoom   قناة Supabase: حضور، دردشة، مزامنة، بث الشاشة
lib/            archive.ts (المكتبة المجانية) · cinemeta.ts · servers.ts · rtc.ts · subtitles.ts · media.ts
public/         logo.png
```

## ملاحظات

- سيرفرات الكتالوج العالمي هي iframes خارجية؛ بعضها يرفض العمل بوضع Sandbox، لذلك هو متوقف افتراضياً لها ومفعّل افتراضياً للروابط الخارجية، ويمكن تبديله من الغرفة ويُزامَن بين الجميع.
- روابط `.mp4` / `.webm` / `.m3u8` / YouTube التي تلصقها بنفسك تُزامَن كاملاً.
- غرف Supabase Broadcast عامة: من يعرف كود الغرفة يستطيع الدخول. لا تشارك الكود إلا مع أصدقائك.
- المشروع للاستخدام الشخصي؛ المحتوى المعروض من الكتالوج العالمي يأتي من خدمات طرف ثالث وأنت المسؤول عن استعماله.
